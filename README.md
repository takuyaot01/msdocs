## このリポジトリについて

日本マイクロソフト株式会社が企画・監修し、株式会社エストディアンが執筆した、日本語の構築・移行ガイドを保管しています。Microsoft 365 やクラウドのセキュリティ設定、Microsoft Sentinel の移行手順を、**PDF 形式**でダウンロードできます。

> 資料は発行時点の製品名・機能・画面に基づいています。現在の仕様とは異なる場合があるため、評価・検証用の参考資料としてご利用ください。最新情報は [Microsoft Learn](https://learn.microsoft.com/ja-jp/) をご確認ください。
